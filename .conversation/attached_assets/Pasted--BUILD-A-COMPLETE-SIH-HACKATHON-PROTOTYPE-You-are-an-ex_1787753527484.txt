# 2. UNDERSTAND THE ACTUAL PROBLEM

The core problem is:

INCOIS generates large volumes of numerical ocean model data.

This data can contain:

* Temperature
* Salinity
* Current vectors
* Chlorophyll
* Depth
* Latitude
* Longitude
* Time

INCOIS also receives observational data from instruments such as:

* Argo floats
* Underwater gliders
* CTDs
* BGC instruments
* Moorings
* ADCP
* HF radar

These datasets can contain:

* Latitude
* Longitude
* Depth
* Timestamp
* Temperature
* Salinity
* Chlorophyll
* Current information

The problem is that these datasets are difficult to explore together in one intuitive browser-based 3D environment.

The application we build must solve this.
